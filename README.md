# Readers' Hub 📚

## About
Readers' Hub is a Flutter mobile application for book lovers and comic enthusiasts. It allows customers to browse books, comics, and accessories, customize products, manage their shopping cart, and place orders. An admin interface provides access to product listings and customer orders.

## Technologies Used
- Flutter
- Dart
- SQLite

## Features
- Customer registration and login
- Admin login
- Product catalog for books, comics, and accessories
- Product customization options
- Shopping cart and order summary
- Order storage and management using SQLite
- Admin access to products and customer orders

## What Users Can Do
- Create an account and log in
- Browse available products
- Customize product options, including format, size, color, and add-ons
- Add items to the cart and review prices
- Place orders
- View products and incoming orders through the admin interface

## How It Works
1. Users choose between the admin and customer interfaces.
2. Customers register or log in using locally stored account data.
3. Customers browse the catalog and select products.
4. They customize their selections and add them to the cart.
5. The application calculates the order total and saves order details in the database.
6. The admin reviews the product catalog and incoming orders.

## What I Learned
- Building mobile interfaces with Flutter and Dart
- Managing local data using SQLite
- Implementing registration and login workflows
- Using Flutter widgets for product customization
- Organizing product, cart, and order data
- Calculating prices and handling shopping cart operations

## Future Improvements
- Replace hard-coded admin credentials with secure authentication and role-based access.
- Store passwords securely instead of saving them as plain text.
- Add an online backend and cloud database for shared data and remote access.
- Integrate online payment methods and order status tracking.
- Add product search, filters, and favorites.
- Add customer order history and notifications.
